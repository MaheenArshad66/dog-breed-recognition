# 🐶 Dog Breed Recognition AI

## 📌 Project Overview
Dog Breed Recognition AI is a Deep Learning project that identifies a dog's breed from an uploaded image. The system uses a trained MobileNetV2 model to classify images into five dog breeds and display the prediction confidence.

## 🎯 Objectives
- Identify dog breeds using Artificial Intelligence.
- Apply Deep Learning and Transfer Learning.
- Build a simple, user-friendly web application.
- Display the predicted breed and confidence score.

## 🐕 Supported Dog Breeds
The model is trained to recognize these five breeds:
- German Shepherd
- Siberian Husky
- Beagle
- Golden Retriever
- Pug

## 🧠 Technologies Used
- Python
- TensorFlow / Keras
- MobileNetV2
- Deep Learning
- HTML, CSS and JavaScript
- Vercel
- GitHub

## ⚙️ How It Works
1. The user uploads a dog image.
2. The website sends the image to the prediction API.
3. The trained model processes the image.
4. The system predicts the most likely dog breed.
5. The website displays the breed and prediction confidence.

## 📊 Model Information
- Model architecture: MobileNetV2
- Task: Image Classification
- Input image size: 224 × 224 pixels
- Number of classes: 5

## 👨‍🎓 Academic Project
Developed as a Deep Learning semester project to demonstrate image classification using transfer learning.

## ⚠️ Disclaimer
Predictions are based on the model's training data. Results may vary depending on image quality, lighting, and the dog's appearance.
